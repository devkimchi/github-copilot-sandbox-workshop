# 관찰 기록

이 파일을 `<WORKSHOP_DIR>/evidence/observation.md`로 복사한 뒤 **참가자가 직접** 작성한다. 아래 양식은 실행 결과가 아니다. 기대 결과는 모두 **미검증**이다.

원자료는 사람이 명령 출력을 `evidence/lab-0/`, `lab-1/`, `lab-2/`, `lab-2b/`, `lab-3/`에 저장한다. 정확한 명령과 실행 위치를 함께 쓴다. 토큰, 구독 ID, 실제 credential 내용과 고객 자료를 쓰지 않는다. 앱 내부 `workspace/evidence/summary.md`는 이 관찰 기록과 다르다.

## 환경과 원자료

| 항목 | 실제 값 | 근거 파일 |
| --- | --- | --- |
| OS/build와 실행 위치 | 참가자 작성 | 참가자 작성 |
| Copilot/Node/Git/sbx/aca 버전 | 참가자 작성 | 참가자 작성 |
| CWD와 baseline, sandbox 이름/ID(비공개 보관) | 참가자 작성 | 참가자 작성 |
| 시작 전 설정과 조직 정책 | 참가자 작성 | 참가자 작성 |

## Lab별 관찰(행을 복사해 사용)

| Lab/단계 | 위치와 정확한 명령 | 기대 결과(미검증) | 실제 stdout/stderr와 종료 코드 | 실제 승인/도구 호출/정책 | 전후 hash 또는 diff | 근거 파일 | 판정 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 참가자 작성 | 참가자 작성 | 참가자 작성 | 참가자 작성 | 참가자 작성 | 참가자 작성 | 참가자 작성 | 참가자 작성 |

판정은 `MODEL_REFUSAL`, `APPROVAL_REQUIRED`, `POLICY_DENIED`, `UNSUPPORTED`, `ENVIRONMENT_FAILURE`, `SUCCESS` 중 하나를 쓰고 이유를 적는다. 시간 초과/미실행은 실제 결과에 명시하고 성공으로 채우지 않는다.

모델 거부는 실제 작업 차단 증거가 아니다. 오류만으로 deny라고 단정하지 않으며 정책 decision과 연결한다. transcript가 누락되거나 일부를 가렸다면 범위와 사유를 쓴다.
